## 使い方

```bash
python3 visualizer.py <NOIM出力DIR> アラーム/alarm_sample.json 出力.html
```

- `<NOIM出力DIR>` には `resourceInfo_pds.csv`、`resourceInfo_pPorts.csv`、`resourceInfo_pls.csv`、`resourceInfo_fres.csv` が必要(変換ツールの出力。EC2 で作った場合は、S3 の `output/` から人がダウンロードする)。
- 作られたHTMLをPCのブラウザで開く。インターネット接続は不要。
- 更新するときは、最新のファイルを置いてもう一度実行する。

## 画面の内容

- 装置=点(名前のラベル。14文字で省略し、ホバーで全文)。接続=線(物理=実線、LSP=点線)。同じ2装置の同種の接続は1本にまとめ、線をクリックすると接続名の一覧が出る。
- `active` のアラームがある装置を強調。色は重大度(1 黄、2 橙、3 赤)で、複数あれば最も重いもの。装置をクリックするとアラーム一覧と接続を表示(`recovered` は薄く表示)。
- 上部にサマリ、警告、「対応する装置のないアラーム」。右に凡例と、アラームのある装置の一覧。ドラッグ、ホイールで拡大縮小、背景ドラッグでパン。

## 実装判断

- 読む出力CSVは4種。TL は PLink と1対1で同じ接続のため読まない(二重に描かない)。
- 物理接続は PLink → PPort(`entityNodeId`)→ 装置。LSPは FRE の NC の `_supportingFreRefList` → XC の `raVxmId` → 装置。
- 装置名または装置IDの重複、`alarmId` の重複は、エラーにする(仕様書に「重複は不可」とあるため)。
- 認証情報は、許可リスト方式でHTMLに入れない(装置の id・name・type・座標、アラーム、辺の情報だけ)。
- 埋め込みJSONは `ensure_ascii=True` にして、`< > &` を `\uXXXX` に置き換えた(`</script>` を含む名前でもHTMLが壊れない)。
- 外部URLは使わない。

## 修正(ユーザーの確認後の依頼)

| 依頼 | 対応 |
|---|---|
| 文字が大きくて被っている | ラベルを11→9、12文字までにし(超えた分は「…」)、点同士の距離を広げた。最後にラベル幅の目安で重なる組を押し広げる処理を追加。実データ26装置で重なり0件(最小の点間距離は約64)。初期の表示範囲は、全装置とラベルが収まるように計算する |
| 上部のチップがクリックできない | チップを `button` にした。「装置」=全体表示に戻す、「物理接続」「LSP接続」=その種類の線の表示/非表示、「アラーム装置」「接続なし」=該当装置に注目して他をうす暗くする(再度押すと解除)、「警告」=一覧の開閉。件数0のチップは無効。「対応する装置のないアラーム」のチップも同様 |
| 線がつながっていない点がある | 実データで調査した(下記)。バグではなく、NOIM出力にその接続が無かった。つながっていない12台を左端にまとめ、「接続なし(12)」の見出しとサマリのチップを追加した |

追加テスト7件。全体で68件(既存42件+新規26件)がすべて成功。実データの再生成結果: 装置26 / 物理接続14 / LSP接続8 / 接続なし12 / アラーム装置3 / 警告0。

### 調査結果: 線につながっていない12台

- 12台はすべて `node_type=CE`。どのポートも `entityNodeId` は正しく装置に着いており、読み取りの漏れではない(端が装置に着かない接続の警告は0件)。
- NOIM出力の物理接続(PLink 24本)の端は、CE 以外の14台のポートだけ。CE が持つ19個のポートは、どれも PLink の端になっていない。LSP接続(NC 8本)も CE 以外の装置同士。
- CE をつなぐのは、入力の `VPN回線(BR)` サービス19本(1本が CE の物理ポートと CER 側の「VPN回線」ポートを結ぶ)。変換ツールは、これを接続のリソースにしていない。NOIM出力の `entityLinkId`、`entityServiceId` などは全ポートで空。
- 結ぶ装置の組は12組(CE→CER)、19本。梅田DTCE-A→関西・梅田DTCER2-A 8本、谷町の CE 6台→関西・谷町ビルCER1-A 各1、3台→関西・谷町ビルCER1-B 各1、2台→関西・梅田DTCER2-B 各1。

### ユーザーの判断が必要なこと

CE と CER を結ぶ19本(`VPN回線(BR)`)を、図の線にしますか? 線にするには、次のどちらかが必要で、いずれも新しい規則のため、実装していない。

1. 変換ツール側で、`VPN回線(BR)` を NOIM のリソースとして出力する。
2. 可視化が、入力のサービスCSVも読む。
