# SLO Config: NOIM変換ツール(dev)

**SLO は設けません。**

## 理由

| 観点 | 内容 |
|---|---|
| サービスの性質 | 常時動くサービスではなく、人が必要なときに実行するバッチ。「稼働率」を約束する相手がいない |
| 利用者 | デプロイした本人だけ(PoC) |
| 計測の元 | 実行回数や成否を集計する仕組み(メトリクス、CloudWatch Logs)が無く、SLI を計算できない |
| 目標を決める根拠 | 運用実績(2〜4週間の計測)がない。実績の無い目標は、決めても検証できない |

## 将来、SLO を設けるとき(参考。今回は採用しない)

日々の運用に載せる場合の候補です。採用する場合は、計測の仕組みと一緒に、改めて決めてください。

| SLI | 候補の目標 | 計測の窓 |
|---|---|---|
| 変換の成功率(実行が終了ステータス 0 で終わった割合) | 99%以上 | 30日のローリング |

計測するには、`noim-run` の結果を CloudWatch に送る仕組み(ログの転送、またはカスタムメトリクス)が必要です。
