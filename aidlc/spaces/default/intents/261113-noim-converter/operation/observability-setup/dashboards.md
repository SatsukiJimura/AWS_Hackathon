# Dashboards: NOIM変換ツール(dev)

**専用のダッシュボードは作りません。** 利用者は1人で、使うのは変換を実行するときだけのため、EC2 のコンソールの標準の「モニタリング」タブで足ります。

## 見る場所

| 見たいこと | 場所 |
|---|---|
| EC2 が壊れていないか | EC2 コンソール → インスタンスを選択 → 「ステータスチェック」(2/2 に合格)と、「モニタリング」タブ |
| アラームの状態 | CloudWatch コンソール → アラーム → `StatusCheckFailedAlarm`(OK / データ不足 ならよい) |
| CPU の使われ方 | EC2 の「モニタリング」タブ → `CPU 使用率`(t3.micro で足りているかの目安) |
| 変換の成否 | `sudo noim-run` の出力と `/var/log/noim-run.log`(`log-queries.md`) |

## 4つのゴールデンシグナルの扱い

| シグナル | この構成での扱い |
|---|---|
| レイテンシ | 計測しない(変換にかかる時間は、実行時に画面で分かる程度。実データで数秒以内) |
| トラフィック | 計測しない(人が実行した回数。S3 の `output/` の更新日時で分かる) |
| エラー | `noim-run` の終了ステータスとエラーメッセージ(`alarms.md` の「エラー率」を参照) |
| サチュレーション | CPU は標準メトリクスで見られる。メモリ・ディスクは CloudWatch エージェントを入れていないため見えない |

## 将来、ダッシュボードが必要になったとき

利用者が増える、実行を自動化する、などの場合に、CDK で `CloudWatch Dashboard` を足します。そのときに依頼してください。
