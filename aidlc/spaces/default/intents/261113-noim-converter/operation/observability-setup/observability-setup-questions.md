# Observability Setup Questions

この段階で新しく聞くことはありませんでした。この構成(人が実行するバッチ、EC2が1台、利用者は本人だけ)では、次のとおり判断しました。判断を変えたい場合は、承認のときに伝えてください。

| 確認する内容 | 決めたこと |
|---|---|
| 追跡するシグナル(レイテンシ・トラフィック・エラー・サチュレーション) | EC2 の標準メトリクス(ステータスチェック、CPU)と、`noim-run` の終了ステータス・ログ。詳細は `dashboards.md` |
| SLO / SLI | 設けない(`slo-config.md`) |
| ダッシュボード | 作らない。EC2 の標準の「モニタリング」タブを使う(`dashboards.md`) |
| ログの保存期間と集約 | EC2 のファイルのまま。CloudWatch Logs へは送らない(`log-queries.md`) |
| 分散トレース | 使わない(`tracing-config.md`) |
| アラームの通知先 | なし。メール通知が必要なら依頼してください(`alarms.md`) |
