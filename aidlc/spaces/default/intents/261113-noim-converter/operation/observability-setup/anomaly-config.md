# Anomaly Config: NOIM変換ツール(dev)

**異常検知(CloudWatch Anomaly Detection)は設定しません。**

| 理由 | 内容 |
|---|---|
| 学習するデータ | 異常検知は、一定のパターンがあるメトリクスのベースラインを学習する。この環境は、人が実行したときだけ動くため、安定したパターンがない |
| 対象のメトリクス | 監視しているのは EC2 のステータスチェックだけで、静的なしきい値(`alarms.md`)で足りる |
| 費用 | 異常検知は、追加の費用がかかる |

利用が常時になり、メトリクスにパターンができた時点で、再検討してください。
