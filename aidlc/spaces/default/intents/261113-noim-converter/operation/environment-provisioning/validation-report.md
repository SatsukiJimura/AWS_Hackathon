## セキュリティの確認(Operation の指針に基づく)

| 観点 | 内容 | リスクと判断 |
|---|---|---|
| IAM | EC2 のロールは、SSM接続、S3 `input/*` の読み取り、`output/*` への書き込み、アセットの読み取りだけ | `grant_read(role, "input/*")` はバケット全体の一覧取得(List)も含む。バケットに入るのは本ツールのデータだけなので許容 |
| ネットワーク | インバウンドなし、アウトバウンド443のみ。パブリックIPは付くが、受け付けるポートはない | SSH を使わないので、公開ポートは無い。許容 |
| 暗号化 | S3 は SSE-S3、EBS は暗号化、S3 は TLS 必須 | KMS の独自鍵は使わない(PoC)。許容 |
| 削除設定 | S3 バケットは削除時に中身ごと消える | 重要データは置かない前提。機微データを置く場合は `removal_policy` を見直す |
| 既存の防御の除去 | 該当なし(新規作成のみ) | |
